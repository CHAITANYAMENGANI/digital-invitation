ANVI & VALLABH WEDDING INVITATION

Files:
- index.html: page structure and invitation content
- style.css: design, responsive layouts, local fonts, animations
- script.js: countdown, event cards, calendar downloads, scrolling and journey animation
- assets/: supplied watercolor background, couple illustration and local WOFF2 fonts

Run:
1. Keep the folder structure unchanged.
2. Open index.html in a browser, or use VS Code Live Server.
3. The invitation uses local fonts from assets/fonts; no Google Fonts connection is required.

Notes:
- RSVP and the fixed sticky RSVP bar are visually hidden, not deleted, so their existing markup and data remain available.
- The countdown targets the first celebration on 18 November 2026.
- Existing event data and calendar/itinerary logic are retained.
